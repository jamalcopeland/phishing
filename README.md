# 📧 Phishing Email Classification Application

🚨 A machine learning application that detects **phishing emails** by analyzing raw email text using **natural language processing (NLP)**.

This project is implemented in a **Jupyter Notebook**, where you can walk through the **entire machine learning pipeline** — from data loading and cleaning, to model training, evaluation, and live user testing.

### 🔍 What You’ll See in the Notebook
- 📊 Data exploration and class distribution visualizations  
- 🧹 Data cleaning and label encoding  
- 🧠 TF-IDF text vectorization  
- 🤖 Logistic Regression model training  
- ✅ Model evaluation (accuracy, confusion matrix, precision/recall)  
- ⌨️ Interactive email input to test custom messages  

### 📂 Project Links
- 📓 **Jupyter Notebook:** [Open the Phishing Email Classifier Notebook](./capstone.ipynb)
- 📄 **Project Proposal:** [View the Project Proposal (PDF)](./PhishingApplicationProposal.pdf)

The trained model achieves **~96% accuracy** on unseen test data and can classify emails as **Safe** or **Phishing** in real time.

**Tech Stack:** Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · Jupyter  
**Use Case:** Email security · Threat detection · Applied machine learning
